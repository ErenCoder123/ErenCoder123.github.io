# Miguel Cardoso — Portfólio

Portfólio pessoal com projetos de desenvolvimento web, back-end, mobile e inteligência artificial.

**Site:** https://erencoder123.github.io/

## Tecnologias

HTML, CSS e JavaScript, sem dependências de build. Hospedagem gratuita no GitHub Pages.

## Editar o conteúdo

- `index.html`: apresentação, projetos, habilidades, experiências e contatos.
- `styles.css`: identidade visual e estilos responsivos.
- `app.js`: filtros de projetos e cópia do endereço de e-mail.
- `assets/`: currículo, favicon e imagem do RetroVault.

O currículo atualizado fica em `assets/curriculo-miguel-cardoso.docx`. Substitua esse arquivo para atualizar o download. Para incluir um projeto, siga a estrutura de um `article.project-card`, defina as categorias em `data-category` e atualize a contagem do filtro Todos.

## Publicação

GitHub Pages publica a branch `main` a partir de `/` (raiz). Alterações enviadas para essa branch atualizam o site automaticamente.

## Fontes

Conteúdo baseado no currículo fornecido por Miguel e em seus repositórios públicos. A imagem do RetroVault vem do README do projeto. O fluxo do Escuta AI é ilustrativo. O Escuta AI é uma prova de conceito com dados sintéticos e revisão humana, desenvolvida com assistência do OpenAI Codex.
