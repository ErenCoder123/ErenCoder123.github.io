01 / INTELIGÊNCIA ARTIFICIALDESTAQUE

Escuta AI

De feedbacks dispersos a uma fila de investigação. Classificação local de tema e sentimento, com revisão humana.

  • JavaScript
  • Naive Bayes
  • Testes automatizados
Contexto e decisões +

O problema

A experiência em suporte de internet motivou a ideia de organizar comentários e identificar assuntos recorrentes. A prova de conceito explora esse problema em um cenário fictício de e-commerce.

O que construí

Dois classificadores Naive Bayes em JavaScript, importação de CSV, pistas da classificação, correção humana e exportação dos resultados. O processamento ocorre no navegador, sem API de inferência.

Avaliação e limites

Em 30 exemplos sintéticos: 70% de acurácia em tema e 73,3% em sentimento. 24 dos 30 casos foram sinalizados para revisão. Esses resultados não demonstram desempenho em dados reais nem ganho de produtividade.

Projeto de portfólio com dados sintéticos, desenvolvido com assistência do OpenAI Codex. Sem cliente real ou uso em produção.

02 / DESENVOLVIMENTO WEBDESTAQUE

RetroVault

Uma loja de jogos retrô com catálogo, carrinho, controle de estoque e gerenciamento de produtos.

  • React
  • Tailwind CSS
  • Context API
  • JSON Server
Contexto e decisões +

O que construí

SPA acadêmica com navegação entre catálogo, detalhes, carrinho e formulários de produtos. Busca, filtros e ordenação ajudam a explorar o catálogo.

Escolhas técnicas

Context API para compartilhar o estado do carrinho; validações de estoque e formulários; foco no primeiro campo inválido; tratamento de carregamento e erros nas requisições.

Simulação de e-commerce com API REST fornecida pelo JSON Server. Sem processamento real de pagamentos.
